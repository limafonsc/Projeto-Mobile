# MovieHub - Gerenciador de Filmes

O MovieHub é um aplicativo mobile para gerenciamento e catálogo pessoal de filmes. Desenvolvido como projeto prático para o curso de Desenvolvimento de Sistemas, o app oferece uma interface que permite aos usuários acompanhar suas estatísticas de consumo de mídia, favoritar títulos, pesquisar por categorias e gerenciar seu próprio catálogo de filmes.

## Funcionalidades Principais

O aplicativo conta com uma experiência de usuário robusta, englobando as seguintes telas e recursos:

### Autenticação e Perfil
* Splash Screen: Tela de abertura com carregamento dinâmico do app.
* Tela de Login: Autenticação segura com opção de login tradicional ou via provedores externos (Google e Apple).
* Cadastro de Usuário: Criação de conta com upload opcional de foto de perfil.

### Painel Principal e Catálogo
* Tela Inicial (Home): Dashboard com resumo numérico do usuário (Total de filmes, Assistidos, Quero assistir e Favoritos), além de seções rápidas para Filmes Recentes e Favoritos.
* Listagem Geral: Visualização de todos os filmes cadastrados com filtros rápidos por status.
* Detalhes do Filme: Ficha técnica completa contendo sinopse, diretor, ano de lançamento, data de adição ao app e sistema de avaliação por estrelas (0 a 5).

### Gerenciamento
* Cadastro de Filme: Formulário para adicionar novos filmes com upload de capa (Câmera ou Galeria), gênero, duração, descrição, status e link do trailer no YouTube.
* Edição de Filme: Alteração flexível de qualquer informação de um título já cadastrado.

### Busca, Filtros e Organização
* Tela de Pesquisa: Busca preditiva por título, gênero ou diretor com histórico de pesquisas recentes salvos.
* Filtros Avançados: Refinamento preciso por gênero, status, intervalo de anos e nota mínima.
* Agrupamento por Gêneros: Navegação categorizada (Ação, Comédia, Drama, Ficção Científica, etc.) indicando a quantidade de títulos em cada uma.

## Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias e ecossistemas:

* Framework Principal: React Native com Expo
* Linguagem: TypeScript
* Navegação: React Navigation

## Como Executar o Projeto
Para a execução, você vai precisar ter instalado em sua máquina o Node.js e um gerenciador de pacotes (como npm ou yarn). Para testar no celular, instale o aplicativo Expo Go (disponível na Google Play Store ou App Store).
